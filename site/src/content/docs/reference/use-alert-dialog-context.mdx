## Import

```tsx
import { useAlertDialogContext } from "@videojs/react";
```

## Usage

Use this hook to build a custom part rendered inside `AlertDialog.Root`.

```tsx
function CustomCloseButton() {
  const { dialog } = useAlertDialogContext();

  return <button onClick={() => dialog.close()}>Close</button>;
}
```

The hook throws when there is no surrounding `AlertDialog.Root`.
